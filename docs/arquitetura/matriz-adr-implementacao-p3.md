# Matriz de ADRs e implementação do P3

Base `3e4c4e3`. O P2 §8.6 registra a arquitetura alvo e os [ADRs versionados](../adr/README.md) registram as decisões aceitas no repositório. Os status abaixo são julgamentos técnicos desta revisão. O [relatório ATAM](avaliacao-arquitetural-p3.md) vincula os julgamentos aos pontos sensíveis, trade-offs e condições ainda abertas.
